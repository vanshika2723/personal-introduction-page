# Personal Introduction Page

A simple and responsive personal introduction website built using **HTML5 and CSS3**. This project presents personal information, skills, hobbies, and contact details in a clean and user-friendly layout.

## 🌐 Live Demo

[View Live Demo](https://vanshika2723.github.io/personal-introduction-page/)

## 📂 GitHub Repository

[View Source Code](https://github.com/vanshika2723/personal-introduction-page)

## ✨ Features

* 👩‍💻 Personal introduction and profile section
* 📝 About Me section
* 🛠️ Skills section
* 🎨 Hobbies section
* 📧 Contact information
* 🖼️ Profile image
* 📱 Responsive design
* ✨ Hover effects and smooth scrolling
* 🧭 Navigation links for different sections

## 🛠️ Technologies Used

* HTML5
* CSS3

## 🎯 Objective

The objective of this project is to practice:

* Basic HTML5 elements
* Semantic HTML structure

* Spacing and layout
* Lists
* Responsive web design

## 📚 Sections

### About

Contains a short personal introduction and background.

### Skills

Displays technical skills using a styled list.

### Hobbies

Shows personal interests and hobbies.

### Contact

Provides contact and social profile links.

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/vanshika2723/personal-introduction-page.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional dependencies or installation are required.
